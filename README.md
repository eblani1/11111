# Прыг-скок — большое приключение

Настольный платформер для Windows 10/11 x64: три мира, бег, прыжки, монеты, три сердечка, слизни и финишные флаги. Есть сохранение прогресса, меню, музыка и полноэкранный режим.

## Скачать и запустить

Откройте [последний выпуск игры](https://github.com/eblani1/11111/releases/latest) и скачайте ZIP из раздела Assets. Распакуйте его и запустите `PrygSkok-1.1.0-Windows-x64.exe`. Node.js, браузер, сервер и интернет для игры не нужны.

Управление: стрелки или A/D — бег; пробел — прыжок; P/Escape — пауза; F11 — полный экран.

В выпуске приложены контрольные суммы SHA-256. Сборка не подписана сертификатом издателя. Игровая часть и настольный пакет проверены на Linux, 16 тестов прошли; запуск Windows-бинарника в Windows здесь не проверялся.
